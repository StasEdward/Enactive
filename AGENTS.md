# Проект: Enactive — системный контекст

- Проект задуман так: пользователь ставит задачу, сильная модель строит план выполнения и дробит задачу на мелкие шаги, шаги выполняет другая, более слабая (локальная) модель, а результат прогона получает ревьюер (сильная модель), который выносит вердикт — задание выполнено успешно или нет.
- Проект предназначен для прогона разнообразных задач с помощью AI. Всегда думай шире, чем решение сиюминутной проблемы. Не делай исправления под одну задачу — делай общие исправления.

A task, from start to finish

The work has a beginning.
And something to show for it.

An example workflow: adding a contact form to a website.

01

Assign

Start with what you need.

Give the agent a task in your project. The workspace holds the files, context and history needed to begin.

website / task brief
Add a contact form with name, email and message fields. Validate inputs and cover the submission flow with tests.
02

Execute

A plan you can follow.

The agent breaks down the task, uses tools and records its actions. You can inspect progress as the work moves forward.

✓ Inspect the existing page
✓ Build the form and validation
↳ Run the tests In progress
03

Review

Make the result yours.

Inspect the artifact and its history. With staging enabled, review and apply the file changes before they reach your workspace.

01 / FLEXIBILITY

Bring your model.

Use Ollama locally, Anthropic or an OpenAI-compatible provider. Match the model to the phase of work.

02 / VISIBILITY

Keep the context.

Plans, tool calls and artifacts belong to a persistent workspace. Follow the work beyond a single run.

03 / CONTROL

Set the boundaries.

Choose an autonomy level. Review staged changes and respond when the task needs your decision.

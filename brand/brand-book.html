Enactive

A desktop environment for AI agents. The model is the engine — Enactive is the environment it works in. This is the identity that has to make that difference visible before anyone reads a word.

Command → Intent → Context(+Environment) → Planner → Orchestrator → Worker(role) → Provider → Tool → ToolResult → Artifact → Event → RunRecorder
01 — What the identity has to carry

One intent becomes real, reviewable, recorded action.

Three product truths drive every choice in this system. Nothing here is decoration; each one has a visual consequence you can point at.

Action, not conversation

You assign a task. You don't hand-drive a chat.

→ one hot accent, and it only ever means "something is happening"

A closed loop

Intent, plan, tool, artifact, event, memory — then round again, better informed.

→ the mark is an open loop folding back into its own gap

A place, not a window

Workspace, timeline, environment model, permissions. Software you inhabit.

→ deep neutral ink surfaces; the accent is the only warmth in the room
02 — Primary mark

The Loop

An open circle that turns almost the whole way round, ends in an arrowhead aimed back into its own gap, and holds a solid dot at the centre.

1 · The ring
The run loop. It does not close, because the work is never a one-shot answer — the next run starts from what the last one recorded.
2 · The gap
Where a human decision fits. The autonomy slider is the product's central promise; the mark leaves room for it.
3 · The arrowhead
Direction and return. It points back into the gap, not outward — the loop feeds itself.
4 · The dot
The artifact. The result is at the centre of the mark because it is at the centre of the product — not the reply, the artifact.

04 — Logo usage

Rules that keep it recognisable.

Clear space

Equal to the radius of the centre dot at the size in use — 11 grid units. Nothing enters it, including the page edge.

Minimum size

Mark 20px. Horizontal lockup 120px wide. Below that, the mark stands alone.

The gradient

Only the mark carries it, at 135°, ember-500 → amber-400. Under 32px, flat ember-500.

do

Use the mono files on photography, video and single-ink print.

do

Write Enactive with a capital E, and enactive.dev all lowercase.

don't

Recolour the mark outside the ember/amber ramp, or add a stroke, bevel or shadow.

don't

Rotate it, badge it in a circle, stretch it, or change the mark-to-wordmark gap.

don't

Re-typeset the wordmark live in another face. Use the outlined file.

don't

Write EnActive, enActive, Enactive.Dev — or AIClient, retired 2026-09.

05 — Colour

One hot colour, and a room to put it in.

Ember is the only saturated warm in the system and it carries exactly one meaning: action. Scatter it decoratively and the interface loses its ability to say "look here, something is happening". Click any swatch to copy its hex.

Ember — the accent

Ember never marks a destructive action. Delete, revoke and reject are --danger. On dark use 300–500; on light use 600–700.

Ink — the environment

Nine-tenths of every surface is ink. Light mode sits on Bone #FAF8F5 — warm paper, not white, so ember doesn't vibrate against it.

Autonomy tiers

The product's central control, coloured so the hue itself says how much rope the agent has. Warmth escalates with risk.
